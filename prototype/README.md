# ChatNote 桌面交互原型

2026-10-08：项目更名为 ChatNote，转为独立跨平台软件。产品路线见 [开发计划](../docs/CHATNOTE_PLAN.md)，功能大纲见 [功能清单](../docs/FEATURES.md)。主入口与导出署名已更新；现有存储键保留，以下旧分享包和验证记录属于此前原型阶段。

新名称的单文件演示为 `ChatNote-demo.html`，运行 `npm run build:demo` 可重新生成。旧的 `CodexAnnotation-demo.html` 和分享包保留为历史演示。

这是面向鼠标和桌面窗口操作的独立演示，不是终端聊天，也不是已安装的官方 Codex 的修改版。

## 打开

分享给别人时，发送项目根目录中的 `CodexAnnotation-demo.zip`。对方解压后打开 `CodexAnnotation-demo.html` 即可：它包含所有样式和脚本，无需安装、启动服务或接入模型。也可以单独发送这个 HTML 文件。分享包只包含演示和示例，不包含你的浏览器记录或 Edge 配置。

界面、示例问答和导出内容已改为深色英文版。为了保留旧中文记录的原文锚点，新版使用独立存储空间，旧数据未删除。

在文件夹中双击 `Launch-Prototype.cmd`。启动脚本会使用已安装的 Microsoft Edge 打开不带地址栏的应用窗口，并将演示数据保存在此目录下的 `.desktop-profile` 中。无需安装额外依赖，不需要 API Key。

这是用 Edge 应用窗口承载的交互原型，尚未打包成独立安装程序。启动脚本的路径、语法和参数已检查；本轮界面交互验证在 Codex 内置浏览器完成，未实测 Edge 独立窗口启动。

也可以直接用现代浏览器打开 `index.html`。开发预览：在此目录运行 `npm start`，访问 `http://127.0.0.1:4173`。使用不同浏览器或打开方式时，本地保存的数据可能不共享。

## 可以体验

1. 悬停在黄色原文上，查看批注摘要；点击展开右侧完整问答。
2. 选中同一段落内的一段文字，点击“批注追问”，输入问题并发送。
3. 在右侧继续追问，主线消息保持原来的顺序。
4. 在右侧的示例回答中选择文字，可以建立子批注。
5. 打开“追问树”，展开或收起子节点，点击问题返回对应批注。
6. 点击“回到原文位置”，定位到主线或上一层批注。
7. 继续主线，例如输入“接下来讲多头注意力”。
8. 关闭并重新打开后，记录在相同浏览器和打开方式下恢复。
9. “导出笔记”生成包含主线、引用原文和递归追问的 Markdown，可预览、全选复制或下载。文件下载取决于承载浏览器的下载支持。
10. 有用的批注结论可以明确带回主线。

输入框支持 Ctrl+Enter 发送。批注高亮可以用键盘聚焦，按 Enter 打开。

新版按钮对应：**Ask in annotation** 创建批注；**Follow-up tree** 打开追问树；**Jump to source** 回原文；**Export notes** 导出。`SHARING.md` 提供英文演示说明。

重置：点击顶部 **Reset demo**，再点击 **Restore original examples**，恢复初始示例。点击 **Cancel** 可取消。重置会替换当前原型的保存记录，需要保留时先导出笔记；无需使用浏览器控制台。

## 目前的边界

- 所有助手回答均为预设示例，未接入模型；任意新问题不会获得真正的模型推理。
- 支持单段落内的文本锚定；跨段落、公式排版、代码块等需要后续扩展。
- 主线与批注只保存在本地浏览器存储中，未实现账号同步。
- 单文件离线打开时，本地存储取决于浏览器权限；移动文件或更换浏览器后，可能无法读取原来的保存记录。需要保留内容时，请导出笔记。
- 暂未提供回答编辑或重新生成，锚点绑定当前保存的原文。
- 此原型不会读取官方 Codex 聊天记录或登录凭据。

## 项目位置

- `index.html`：界面入口。
- `app.js`、`app.css`：交互与样式。
- `core.js`：文本锚点和关系校验。
- `Start-Prototype.ps1`、`Launch-Prototype.cmd`：独立桌面窗口启动入口。
- `serve.js`：仅监听本机的开发预览服务。

后续接入 Codex App Server 时，可以继续使用这个界面，将示例回答替换为真实会话；批注锚点、父子关系和学习记录由本项目保存。

# ChatNote v0.3.1 · 公式批注悬停提示

日期：2026-10-08。

## 改进

- 公式的“批注该公式”入口默认隐藏，浮动在公式上方，悬停或键盘聚焦时出现。
- 提示不占正文空间；点击后使用原始 LaTeX 和原文偏移建立批注，已有批注直接打开。
- 键盘聚焦公式后按 Enter/空格可批注；提示按钮也可通过键盘访问。触摸使用聚焦后的提示入口。
- 英语/简体/繁体资源同步。原有公式渲染、代码批注、私人笔记和上下文预览保留。

## 登录保留检查

用户反馈本轮已能重新登录。只枚举系统凭据条目名称，当前会话和注册条目均存在，未读取/输出真实令牌。

代码使用固定的 app.chatnote.desktop、ChatNote 凭据服务和固定条目名称；正常关闭窗口保存记录后销毁窗口，不执行退出登录；只有明确断开账号才清除该账号的会话令牌。已有自动刷新代码使用保存的 refresh token，临时网络失败保留会话。

单独重新执行跨进程持久化检查：两个独立原生进程写入/读取随机合成凭据成功，并清理该测试条目。真实账号跨本版安装恢复和真实过期续期仍待用户实测，不把测试凭据验证当作真实 OAuth 验收。符合[官方会话与凭据说明](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)。

## 使用

先关闭旧程序，再运行 [安装包](../releases/archive/v0.3.1/ChatNote_0.3.1_x64-setup.exe)或[直接启动程序](../releases/archive/v0.3.1/ChatNote_0.3.1.exe)。升级不用先断开账号；保持注册和会话存储位置不变。

仍是未签名 Windows 内测版；外部授权页异常、真实账号续期和跨平台继续分别验收。触屏聚焦入口尚未移动真机验收。

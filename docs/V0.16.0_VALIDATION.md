# ChatNote 0.16.0：支线汇合、全屏画布与离线导出

2026-10-22。用户确认开始0.16.0构建，并要求同步仓库、版本文件、统一 UI/动效与导出。默认将研究成果带回主线，同时支持新建独立汇合讨论。公开下载与自动更新清单在正式发行前保持0.15.0。

## 使用

1. 在追问面板点击“带回主线”，或在追问树标题栏点击“汇合讨论”。画布中也可以复选/按住 Shift 拖动框选追问，再点击“汇合讨论”。
2. 默认选择带回主线；如需单独探索，选择新建汇合讨论。核对来源、实际引用材料及字符数后确认。共同的连续历史前缀按角色、原文和附件元数据精确比较；只去掉相同连续前缀，不做语义合并或判断分歧。
3. 确认只在本机保存快照，不自动调用模型、总结或发送草稿。原有主线消息、追问、来源锚点、私人笔记和未发送草稿保留。已有主线上下文选择保留，并将新增材料加入选择；之后仍可在上下文预览里排除。
4. 主线“汇合讨论材料”可展开查看全文，并点来源返回对应追问。旧消息版本仍存在时会打开当时的讨论路径；来源被改写/移除或没有随备份导入时，保留快照并明确提示来源不可用。后续变更不自动同步，用户可再次带回；无新增内容时不重复追加。
5. 顶部“思维导图”进入默认全屏工作画布，可缩小窗口；卡片正文在侧边阅读。拖动卡片标题移动，拖动空白平移，滚轮或工具栏缩放，0适应全部，+/-缩放。复选与框选用于选择追问，原文锚点不因拖动改变。布局撤销只针对本次打开期间的排列/折叠操作；保存的布局、折叠和视口随会话恢复。窗口尺寸改变时重新适应，避免窄窗口看不到节点。
6. 右上角“导出选项”保留分享/个人留存范围；底部导出 HTML。离线文件采用同一套卡片/连线/阅读面板与240ms平滑动效，遵守减少动态效果；支持明暗主题、平移缩放、拖动、自动排列和打印正文。离线操作不回写应用，禁用脚本仍可阅读正文；固定哈希只允许内置控制脚本，原文不作为脚本执行。
7. “设置 → 一起改进 ChatNote”显示贡献者 sinpangky 的 GitHub 名称和主页，不展示贡献内容或加载远程头像。

## 数据与兼容边界

数据库格式仍为0.15.0的v2，本版只增加可选消息来源元数据与会话视图字段，不重置工作区，不写系统凭据库。按会话存储的文本池复用来源快照文字；工作区导入会映射同批导入会话的来源 ID，不指向本机可能同名/同 ID 的旧记录。导出的范围控制不等于自动脱敏：已经写进讨论正文的内容和附件名称仍属于正文，需要分享前自行核对。合并材料只引用附件名称，不复制附件字节或提升其中指令的权限。

回退0.15.0沿用同一v2数据库，但旧版不认识画布/来源交互；回退前先导出完整备份，升级后新增功能建议使用0.16.0继续管理。0.14.0不能直接读取v2，必须遵守此前的升级前数据库备份恢复规则。当前0.15.0/0.14.0及更早交付字节保留，本版不替换同名历史文件。

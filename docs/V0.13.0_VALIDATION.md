# ChatNote 0.13.0 使用与验证

日期：2026-10-17。Windows x64正式版本；新增自动更新与源码公开。

## 使用

启动后后台检查并下载新版，不发送模型推理。下载完成后可以继续使用，点击“重启并更新”立即安装；未点击时，下次启动自动安装已下载且通过验签的包。没有完整缓存则不会执行安装。设置 → 关于提供手动检查、进度与下载重试。

更新前保存当前工作区及阅读位置；保存失败停止安装。生成、录音、整理和文件操作时不立即重启。Windows安装阶段会退出应用，完成后重新打开。失败后保留当前版本与记录；上次安装未完成时暂停自动重试，避免启动循环。开发和浏览器预览关闭更新执行。

## 发行结构

应用源码仓库公开，采用PolyForm Perimeter 1.0.1（源码可见，限制用于竞争产品）。应用仓库负责0.13.0起的新Release，官网仓库维护网页、各版本下载元数据及updates/stable.json；旧资产保留。

更新包签名强制绑定版本，HTTPS下载；私钥保存在维护者Windows系统凭据库，不在源码、网页或日志中。Tauri更新签名与Windows代码签名不同，当前未购买发布者证书。

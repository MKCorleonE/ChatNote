# ChatNote 0.12.0 · 记住上下文与个人空间

日期：2026-10-13。Windows x64。沿用工作区版本1、SQLite结构和系统凭据库；新增可选的回收站与上下文选择元数据，不重置原会话、锚点、草稿、附件、连接或ChatGPT注册。

## 最终行为与使用

1. 主线、追问与编辑后重新生成均默认直接发送，不自动打开上下文预览；预算缩略也直接发送并提示，可在回答旁查看实际请求收据。主动点击预览才选择范围。主线默认携带当前主线历史，不含追问；追问默认携带截至原回答的来源快照和本条追问历史，不含后续主线、兄弟追问或私人笔记。
2. 每条主线和追问分别记住主动选择，按原消息ID/版本、来源快照位置匹配，不用易漂移的数组索引或文字模糊匹配。选定范围跨发送、切换、重启保留；新增历史不自动加入，当前问题和精确引用保持携带。恢复默认上下文清除本条自选范围。新建追问保存后继承选择；实际请求收据只保存已发送内容。
3. 工作区语言尚未加载时启动只显示品牌与等待动画，加载后才显示对应语言标语，并完整展示启动动画，避免先闪英文。
4. 偏好设置新增隐私、回收站和实验室，原数据栏目改为数据与备份。三语隐私政策覆盖本机保存、系统凭据、模型上下文/附件/音频、第三方服务、保留与清理、备份/导出、反馈及联系方式。不把未实现的本机加密、第三方删除或磁盘安全擦除当成承诺。[三语政策全文](PRIVACY_POLICY.md)与应用文案一致。内容参考[官方个人信息保护法告知事项](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)，按当前实际产品能力撰写，不声称完成法律合规认证。
5. 整个对话删除后进入回收站，连同追问、笔记、草稿、旧版本、锚点和附件保留24小时。达到24小时后，在下一次启动读取工作区时清理；不会在阅读中到点自动清理。清理前可恢复，支持勾选恢复、勾选立即删除和红色清空按钮。永久删除先确认，取消保持原记录。
6. 永久清理通过本机事务同时更新工作区、剔除相应SQLite恢复快照中的对话并清理不再被任何保留记录引用的附件；共享附件、其他对话和凭据不动。保存队列保证旧保存先于清理，不在清理中写回旧回收站。清理失败保留可恢复记录并报错。浏览器隔离预览用IndexedDB对应事务。单条回答删除沿用原行为，不进入对话回收站。
7. 关于→开源许可下新增“一起改进ChatNote”，包括建议与反馈、加入开发计划；统一邮箱529023573@qq.com和小红书号1006863642，支持复制，不自动发送消息、不招募合作者或改变仓库权限。实验室只显示“实验功能待开放”。页面、按钮与确认框沿用弹性动效和系统减少动态效果设置；删除确认在顶层显示以避免被设置动画裁切。

隔离浏览器1421端口：过期25小时的合成对话在加载后清理，1/2小时的两个条目保留；恢复完整追问关系、红色清空确认/取消、实验室占位、两个联系板块与复制反馈正常。主动选择2/6上下文、关闭重开和重载均保留2/6，恢复默认变回6/6且草稿保留。简体/繁体/英文隐私及新导航正常；390px时设置窗口364px、页面及联系卡无横向溢出，导航独立滚动；浏览器无警告/错误。证据在`.desktop-test/v0120/`，没有处理真实用户回收站或发模型请求。

真实账号推理、录音设备、覆盖安装、长时间日常使用与动画手感仍待用户验收。开发者反馈数据需按政策执行；本轮未替用户发邮件/小红书消息或建设官网。旧版0.11.0没有回收站管理界面，回退前请在0.12.0导出完整工作区备份，且由0.12.0恢复/清理回收站；不将旧版备份的附件覆盖范围扩展为支持新字段。

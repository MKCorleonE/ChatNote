# ChatNote v0.5.0 · 胶囊侧栏与分区设置

日期：2026-10-08。

## 本版行为

- 左栏顶部使用同一竖向胶囊，依次是加号新建、三道横线历史、齿轮设置，共三个按钮。没有协作入口。
- 按钮提供悬停、按压缩放与图标微动；历史面板圆角悬浮展开，设置使用淡入与轻微缩放。开合保留退出过渡，快速重开会取消旧的卸载计时。遵循系统减少动态效果偏好。
- 设置左侧导航分为偏好设置和关于：模型与连接、阅读与上下文、外观、数据与隐私、关于、更新日志、开源许可。
- 现有模型、账号、密钥、连接检查和余额操作集中在“模型与连接”；字体、主题、语言和输入框光效放在“外观”；批注与上下文预算放在“阅读与上下文”。
- 分区切换保留未保存的表单编辑；点击“完成”沿用原保存流程，关闭则放弃尚未保存的编辑。语言仍即时应用。切换分区后内容滚动回顶部；设置支持 Escape、键盘焦点循环及关闭后的焦点恢复。
- “数据与隐私”接入原完整备份和非破坏性导入。导入作为新副本添加，连接和已有对话保留；生成期间导入/备份入口禁用。
- “关于”显示版本和项目入口；“更新日志”在本地提供 v0.1.0–v0.5.0 的简明记录与私有 Release 入口。当前更新仍需手动安装。
- “开源许可”可按组件名称或许可证搜索，展开原始语言条款。按锁定版本生成 654 项 npm/Cargo 依赖记录，包含可选平台与构建依赖；615 项带顶层声明正文，39 项明确显示包声明与源码包条款说明。许可数据仅在打开该页时加载。
- 英语、简体、繁体键及插值保持一致。数据库格式、原文、偏移、草稿、连接 metadata、系统凭据服务和 ChatGPT 注册位置沿用原实现。

## 使用与升级

关闭旧版后安装 [v0.5.0 安装包](../releases/ChatNote_0.5.0_x64-setup.exe)，或运行[直接启动程序](../releases/ChatNote_0.5.0.exe)，无需先退出账号。当前目录保留 v0.5.0 和 v0.4.0；v0.3.1 及更早交付文件归档保留。

胶囊从上到下：新建、历史、设置。设置目录中的“外观”调整语言与输入框光效；“关于”组阅读版本、更新日志和开源许可。原有导出入口仍在主界面更多操作中。

许可证清单随锁文件维护，安装依赖后执行 `node scripts/generate-license-notices.mjs` 重新生成；更换依赖需要复查声明和未含顶层正文的条目。

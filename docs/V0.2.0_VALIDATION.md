# ChatNote v0.2.0 · 国际化基础

日期：2026-10-08。语言入口：Settings → Interface language，可选择 English / 简体中文 / 繁體中文，立即生效并保存到本机。

## 最终变化

- 导航、主线、批注、追问树、历史抽屉、设置、连接状态/额度说明、分类错误、确认提示和 Markdown 导出说明覆盖三种语言。
- 独立 JSON 语言资源；未知语言与缺失资源回退英语。数字、日期和时间通过 Intl 格式化，英语数量处理单复数。
- ChatNote 自己的登录完成/失败网页跟随所选语言；服务商登录页面和系统文件对话框由服务商/系统决定语言。
- 旧设置没有语言字段时沿用英语；数据库、程序标识与凭据位置保持兼容。
- 语言切换只保存语言选择，保留设置中尚未保存的连接编辑和密钥输入。不会自动保存这些未完成编辑。
- 原文、历史标题、用户连接名称、模型 ID、批注锚点/偏移、草稿和模型请求上下文保持完整。界面切换不改变模型回复语言，英文示例内容仍是原始英文。

## 已完成验证

- 26 项前端/核心/UI 测试通过：资源键与占位符一致、界面调用无遗漏资源、英语回退、日期与数量、旧工作区、导出原文、三语即时切换、模拟重新打开、保留草稿/未保存编辑，以及已有批注/连接功能。
- 12 项常规 Rust 测试通过，含登录完成网页的三语成功/失败提示与安全回退。两项需要写入系统凭据库的测试本轮未重新执行，保持显式忽略；它们在 v0.1.1 已单独验证。
- TypeScript/Vite production 编译和 Windows release/NSIS 打包完成。Vite 仍有大资源包提示，后续可拆分优化。
- 浏览器实际检查英语→简体→繁体切换、重新加载保留繁体、语言设置和原文批注显示。截图见 [简体界面](screenshots/chatnote-v0.2.0-zh-Hans.jpg)、[繁体设置](screenshots/chatnote-v0.2.0-zh-Hant-settings.jpg)。

## 验证边界

本轮未使用 ChatNote 发起真实模型生成/余额查询，未重新登录或修改真实凭据。Windows 真实升级安装、登录续期、国内厂商请求仍待账号实测。既有 ChatGPT 登录/对话成功来自用户反馈，不能写作本版助手实测。

法语、德语尚未提供；繁体当前是一套通用界面，未细分台湾/香港；动态服务商详情与未知原生错误保留原始内容，已知分类说明已翻译。初次打开本地记录的加载阶段使用英语，记录读出后应用已保存语言。Windows 内测包仍未签名，无自动更新；其他平台尚未交付。

# 0.16.0 设计与维护入口

## 产品关系

汇合记录是不可变的历史资料引用，连线展示来源，不直接改变模型上下文；是否发送由现有的上下文选择/预算与用户提问决定。主线按问答轮次展示，追问按原文分支展示，保持ChatNote的阅读与来源定位。默认带回主线，也能复制当前主线背景建立独立讨论；来源和原讨论继续保留。

## 动效与可访问性

共享全局颜色和控件基础，画布默认240ms `cubic-bezier(.22,1,.36,1)`进入/布局变化，悬停160–180ms；拖动期间关闭位置过渡，避免节点追不上指针。远景只保留较大的标题；近景显示摘录。所有操作有可见按钮与可访问名称，画布支持键盘缩放/适应，窗口保留焦点陷阱、Escape与触发点恢复。`prefers-reduced-motion`关闭过渡/动画；导出复用同一CSS。

## 参考来源

- Branch Local（sinpangky，MIT）：保留来源的分支汇合、独立讨论/回到主干、紧凑画布配阅读面板。
- ThoughtDAG（Xia Chen，MIT）：画布导航、上下文路径表现、卡片与连线交互；其自由连线决定上下文的完整图模型不在本版范围。

本版按ChatNote已有数据结构独立实现，未新增图编辑运行库或移植上游应用；项目自有代码继续使用PolyForm Perimeter 1.0.1，上游项目许可不被替换。

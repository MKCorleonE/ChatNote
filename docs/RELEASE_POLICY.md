## 哪些文件保留

2026-10-13起，经用户明确授权，官网及选定公开下载由独立[chatnote-site](https://github.com/MKCorleonE/chatnote-site)承载。应用源码与原私有Release保留；官网初次分发镜像0.12.0与0.11.0原始程序，不能替换同版本附件。[官网与下载验证](WEBSITE_LAUNCH_VALIDATION.md)。

- **已交付版本**：保留原始安装包、直接启动程序、校验值及该版本验证记录，便于回退与复现。发布后不以同名文件替换不同内容；修复使用新版本号。
- **日常本地开发**：便捷目录保留最新版和上一稳定版，更早版本归档到单独目录或 GitHub Releases。归档前检查文件、校验值与版本说明完整；有可靠归档后再移出便捷目录。
- **临时构建**：开发中未交付、可重新生成的 `dist` / `src-tauri/target` 可以按需清理；清理构建缓存会增加下次编译时间，不应误删 `releases`、验证记录或用户数据库。

## 发布约定

程序、安装包与文档版本一致；每次保存 SHA-256 与变更说明。后续将大型安装包放到发布资产/对象存储，源码仓库保留源码和版本记录。GitHub Releases 支持按标签管理版本并附加二进制资产：[官方说明](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)。

回退前备份用户工作区。较旧程序可能无法读取未来的新数据格式，保留旧 exe 不代表任意版本都能安全降级。客户端已有较新数据库版本保护。

删除已交付文件需要单独明确范围，不随普通升级自动执行。

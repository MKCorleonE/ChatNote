# ChatNote 0.10.0 · 材料输入、上下文选择与学习交互

日期：2026-10-12。Windows x64。此次不修改数据格式、数据库身份或凭据库命名空间；原会话、锚点、草稿、附件、连接及 ChatGPT 注册均继续沿用。

## 使用方式

1. 主对话或追问输入框中直接 Ctrl+V 粘贴截图，不增加粘贴按钮。普通文字粘贴继续使用原行为；附件入口仍可选择文件。新人引导与连接设置中的附件卡说明图片粘贴及模型能力。每个文件不超过 10 MB，每次请求最多 8 个附件、总计 20 MB。
2. 图片与文字在同一次请求中打包。DeepSeek 选择 `deepseek-flash`；千问选择视觉模型；其他兼容视觉模型可明确开启图片能力。不要用图片能力开关来声称纯文本模型支持视觉。
3. UTF-8 文本、Markdown、CSV、代码等读成文字送入请求；OpenAI API 通过 Responses 的 `input_file` 接收 PDF / DOCX / PPTX / XLSX。千问官方端点的 `qwen-long` / `qwen-doc-turbo` 接收文档上传与 fileid 引用；Qwen-Long 不接受 PPTX，需用 Qwen-Doc 或转 PDF。千问文件在发送时上传，生成结束、失败或停止后尝试删除临时文件；删除失败会明确提醒到服务商 Files 页面清理。文件 ID 与密钥不写入会话或导出。
4. DeepSeek 官方 Files API 当前只接受图片，PDF / Office 暂不上线。报错直接说明 DeepSeek 的限制，不再误称 OpenAI 无法使用。不将任意自定义 Chat Completions 地址当作文档接口。
5. 在设置 → 阅读与上下文选择独立语音连接。自动选择先读取本机连接状态，跳过未配置密钥的连接；没有可用连接时引导设置，不先录音再失败。OpenAI 默认改为 `gpt-4o-mini-transcribe`；旧的错误默认名 `gpt-transcribe` 在请求时转换为有效默认名。千问官方端点默认 `qwen3-asr-flash`，使用 `chat/completions` 的 `input_audio`；其录音限制为 10 MB / 5 分钟，达到录音限制后可转写。硅基流动等提供 `/audio/transcriptions` 的服务可添加自定义连接并填写真实转写模型，例如 `FunAudioLLM/SenseVoiceSmall`。DeepSeek 与 ChatGPT 登录没有此转写接口。录音在用户选择转写前只保留在本机，转写结果可先检查再发送。
6. 追问发送或编辑后重新生成会打开上下文选择。精确引用与本次问题保持携带，其余来源快照、当前追问历史可逐项勾选；可一键仅携带引用与问题。主对话也可用“预览上下文”选择本次历史，完成后直接按当前选择发送。附件随所属历史项选择；切换服务商后可取消不支持的旧附件。发送使用这个请求快照；回答旁的上下文按钮只显示实际发送内容。
7. 上下文预算是本地文字字符预算，不是模型 Token 上限、回答长度或每日配额。每次聊天请求都计算选中文字与文本附件；超出时保留本次问题/精确引用，较旧内容转为标记清楚的摘录，由用户确认发送。不会改写保存的全文。图片及原始文档的 Token 用量由服务商计算，不能由此预算保证。完整固定提示词也可在预览中查看。学习笔记整理使用独立的完整材料预览，不套用此聊天预算。
8. 横向追问概览与思维导图共用连线和卡片尺寸布局。默认 360px，可用滑杆统一调宽至 260–720px，也可拖卡片右下角单独调宽至 800px。父子连线随实际宽度移动，展开细节使用弹性动画。尺寸调整仅影响当前阅读界面，不改原文或锚点。独立 HTML 保持单文件、无远程资源和脚本，也能拖卡片右下角调宽；移动触屏上的原生 resize 手柄支持取决于浏览器。
9. 主对话和同一追问有多轮时显示简洁的轮次刻度。点击刻度跳到对应问题，当前阅读轮次的刻度加长；滚动及大小变化会重新定位。沿用原有阅读位置保存。
10. 全局底部提示统一为 2.5 秒停留、弹性进入与短退出。导出笔记／思维导图真正保存成功后发射彩带并渐隐；取消、失败或普通备份不触发。所有新增动画遵循系统减少动态效果。

## 官方 API 核对

核对时间：2026-10-12。支持 API 不等于本轮真实账号调用通过。

| 连接 | 图片 | PDF / Office | 语音转写 |
| --- | --- | --- | --- |
| OpenAI API | 按视觉模型能力 | Responses 支持文件输入；Office 中嵌入图片不等于完整视觉解析 | audio/transcriptions；有效默认模型 |
| ChatGPT 登录 | 沿用现有图片通路，真实账号待验收 | 当前注册通路未支持，入口不给虚假承诺 | 登录不提供转写接口 |
| DeepSeek | deepseek-flash 支持内联图片 | Files API 只接受图片，原始文档暂不上线；UTF-8 文本可用 | 官方公开 API 未列出转写端点 |
| 千问官方端点 | 视觉模型；可手动声明能力 | Qwen-Long / Qwen-Doc-Turbo 文件上传＋引用；需对应地域和模型权限 | qwen3-asr-flash，短录音 Base64 |
| 自定义兼容端点 | 服务商与所选模型确认支持后开启 | 未盲目启用未知文件协议 | 填写提供 audio/transcriptions 的真实模型 |

## 用户反馈与尚未验收

用户在升级前报告：Ctrl+V 图片不可用、文档上传失败且提示误指 OpenAI、语音转写不可用、导图卡片过窄、缺少连线和轮次刻度、提示停留过久。它们是用户对旧版的反馈，不作为新版已通过的证据。

本轮不使用真实密钥发送图片／文档／语音，也未替用户安装覆盖或改变系统麦克风权限。真实账户权限、模型输出质量、录音设备、升级后登录保留、动画手感与手机文件打开仍待用户验收。千问文档解析等待由服务商负责，本版不自动重发失败的计费请求；大文件解析或临时文件清理失败保留明确错误。未接入 Gemini / Anthropic 独立协议、手写识别、实时语音字幕、图谱编辑、直接 PDF、签名或自动更新。

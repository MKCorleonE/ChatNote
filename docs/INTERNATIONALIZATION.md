# 添加与维护界面语言

当前语言：`en`、`zh-Hans`、`zh-Hant`。资源位于 `src/locales/`；公共格式化/回退在 `src/i18n.ts`，React Provider 在 `src/I18nProvider.tsx`。既有静态文案使用英语原文作为键，带插值的文案使用稳定语义键。

新增语言时：

1. 从 en.json 建立新资源文件，翻译全部值，保留 `{name}` / `{count}` 等占位符名称。
2. 在 Language、languages、catalogs、resolveLanguage、localeTag 中注册语言；若包含单复数规则差异，扩展 plural 并增加用例。
3. 校对长文案、日期/数字、错误提示、无障碍名称与窄窗口。原生登录完成页在 auth.rs 中有少量文案，也需同步。
4. 执行前端测试、原生测试和打包，更新版本记录、功能清单、交付说明。

仅对界面和新创建的默认标题使用翻译。不得翻译已有会话文本、引用、锚点、模型 ID、用户连接名称或模型请求中的上下文指令。服务商详情保留原文，分类与恢复建议翻译。

语言存储在工作区设置中，旧备份允许缺失语言字段，未知语言回退英语。此规则允许跨版本读取备份；不会重写历史内容。

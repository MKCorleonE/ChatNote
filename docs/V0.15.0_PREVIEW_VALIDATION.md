# 0.15.0 开发预览：学习成果留存与检索

2026-10-19，开发版本 `0.15.0-preview.1`。正式发布仍为0.14.0；本轮不发布Release、不替换历史程序、不更新官网安装包或签名更新清单。

## 使用

- 学习笔记中的模型整理稿自动随所属对话保存。生成中每400ms合并一次保存通知，中断保留部分文字；关闭/隐藏页面及退出前刷新最新草稿。重开窗口、重启后恢复；新一轮整理保留上一份非空稿，可切换旧稿、编辑正文。对话变化后显示旧稿提示。提示词预设和私人批注保持原有规则。
- 会话列表搜索覆盖标题、主线/追问问答、历史问答版本、私人笔记与当前整理稿。结果显示命中片段及类型，点击恢复所需消息版本、打开对应主线或追问、滚动并标明目标。搜索不发送模型请求、不改变正文/原文偏移；回收站和未发送草稿不进入结果。结果最多80条，超出提示细化关键词；中文/大小写和Unicode变长小写位置有处理。旧整理稿可在笔记历史中查看，暂未单独全文索引。
- 笔记HTML、导图和Markdown导出前提供分享/个人留存选择。分享预设排除私人笔记、无关历史版本、附件文件和模型整理稿；每类可按需选择。追问必需的历史原文出处仍保留，不能将此当作任意内容的自动脱敏。导图本身不嵌入附件/整理稿，Markdown不打包附件字节，所以这两处不展示无法生效的开关。完整工作区备份不受导出范围影响。
- 复用已有按钮、弹窗与焦点/减少动态效果规则，简中/繁中/英文同步。

## 长会话存储

过去每次把整个工作区序列化并写入单行，20MB上限针对这一份工作区JSON。新实现按对话存储，客户端缓存未变对话的存储编码，保存时只传输和写入变化的会话及较小的工作区目录。每个会话存储上限64MB，不再用旧20MB限制整个工作区。

请求上下文的重复文字在各自会话的存储文本表中共用一份，读取时按原文字节恢复。消息内容、锚点、请求内容及上下文预算策略不改变。搜索使用本机缓存索引和延迟输入，不在每次键盘输入时重新扫描所有正文。

SQLite事务保证目录和会话更新同时提交；保存失败不更新客户端的已保存版本表。每个会话保留最近3次变化的恢复记录。永久删除清理旧工作区快照、新会话记录及其恢复副本，并保留其他会话仍引用的附件。旧存储行仅用于迁移前记录与兼容清理，读取以新存储为准。

首次转换前，数据库旁创建独立 `chatnote.pre-v015.sqlite`；备份创建后或复用前验证SQLite完整性，失败时停止转换。转换成功后数据库版本为2，旧0.14.0会明确拒绝读取，不静默加载过期数据或改写新格式。该升级前备份可能含旧记录，与导出的备份一样独立保留，不被回收站清理改写；设置和隐私政策已说明。

### 回退

预览使用前先导出完整工作区备份。回退时关闭应用，保留当前数据库及其WAL/SHM和新导出的完整备份，再从独立升级前备份恢复旧版本；不要让0.14.0直接读取已转换的数据库。升级后的新内容应另行保存，不能靠升级前备份恢复。凭据和ChatGPT注册在原系统凭据库，不因更换工作区数据库而清除。

## 自动与助手验证

- 前端全量163项、Rust原生34项通过，5项原有显式忽略；TypeScript/Vite生产构建、Rust格式检查通过。原生覆盖旧数据备份/转换、失败事务回滚、只更新变化会话、清理新旧恢复记录、超过旧20MB的完整文字存取。前端覆盖整理稿/部分稿/旧稿、编辑回传、搜索旧路径/Unicode偏移、导出排除和编码无损还原。
- 浏览器使用独立端口1422及合成导入记录，未读取或修改个人工作区。实际编辑整理稿、关闭、刷新、重新打开后正文仍在；分享模式四项默认排除；搜索“缩放”找到私人笔记，点击后右侧相应笔记获得焦点和定位标记。证据只保存在本机忽略目录 `.desktop-test/v0150/`。
- 未发真实模型请求，未写入/删除真实API凭据，未执行用户真实工作区迁移或覆盖安装。用户尚未验收，不能把模拟流式生成/合成数据扩大为真实账号与日常性能验证。

## 合成性能样例

同机、UTF-8 JSON字节数，含真实应用逻辑生成的上下文报告，不包含真实聊天：

| 问答轮数 | 旧完整序列化 | 新存储编码 | 减少 |
| --- | ---: | ---: | ---: |
| 50 | 9,841,943 字节 | 915,184 字节 | 91% |
| 200 | 109,527,289 字节 | 8,094,865 字节 | 93% |

200轮样例冷序列化旧132ms、新编码149ms；首次编码有额外计算，不能宣称首次编码更快。收益是减少重复文字、后续未变会话不重新编码/写入，和缩小存取数据量。样例首次/缓存关键词查询约1ms/不足1ms，非通用性能保证。完整列表虚拟化、超大导图DOM优化与真实低配机器帧率尚未纳入本版。

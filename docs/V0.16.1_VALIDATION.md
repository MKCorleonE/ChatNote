# ChatNote 0.16.1：贡献者主页修复

2026-10-22，用户明确授权修改并正式发布。相对0.16.0只修复贡献者入口和新增名单，继承0.16.0功能；0.16.0开发构建与验证记录完整保留。此前线上稳定版本为0.15.0。

## 使用与修复

设置 → 一起改进 ChatNote → 贡献者，点击 sinpangky 或 pppp 图标按钮，在系统默认浏览器打开对应主页：

- https://github.com/sinpangky
- https://github.com/pppp-PENG

新贡献者的 GitHub 显示名经公开 API 核对为 pppp。故障原因是桌面外链权限只允许应用仓库等已有地址，未包含贡献者主页。补充两个精确 HTTPS 地址，未放开整个GitHub或任意网址；按钮保留名称、图标、原有交互及打开失败提示。贡献者之间增加与原控件一致的间距。

# ChatNote 0.16.1：贡献者主页修复

2026-10-22，用户明确授权修改并正式发布。相对0.16.0只修复贡献者入口和新增名单，继承0.16.0功能；0.16.0开发构建与验证记录完整保留。此前线上稳定版本为0.15.0。

## 使用与修复

设置 → 一起改进 ChatNote → 贡献者，点击 sinpangky 或 pppp 图标按钮，在系统默认浏览器打开对应主页：

- https://github.com/sinpangky
- https://github.com/pppp-PENG

新贡献者的 GitHub 显示名经公开 API 核对为 pppp。故障原因是桌面外链权限只允许应用仓库等已有地址，未包含贡献者主页。补充两个精确 HTTPS 地址，未放开整个GitHub或任意网址；按钮保留名称、图标、原有交互及打开失败提示。贡献者之间增加与原控件一致的间距。

## 自动检查与助手验证

检查执行中，正式发布前补充实际结果。新增行为回归覆盖按钮实际传递地址、桌面权限对应两条地址，以及启动失败提示；三语键与版本字段同步。

## 数据、回退与限制

本补丁不修改存储、迁移、锚点、草稿、连接元数据或系统凭据规则，不发送模型请求。未重置个人工作区或覆盖历史发行字节。继承0.15.0数据库v2规则，回退到0.14.0须恢复升级前独立备份，详见V0.15.0_VALIDATION.md。0.16.0本地开发文件保留；0.15.0为上一正式稳定版。

助手合成验证与用户验收分别记录：真实账户、个人工作区覆盖安装、低配设备和用户日常使用未验收。Windows发布者Authenticode证书仍未配置，既有更新签名独立验证。

## 正式发布

在最终Windows CI、签名、标签/源码、草稿附件摘要检查通过后发布，再同步官网三语下载和静态更新清单。

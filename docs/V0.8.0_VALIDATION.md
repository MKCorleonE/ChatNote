# ChatNote 0.8.0 · 学习路径、材料与离线笔记

日期：2026-10-11。Windows x64 正式升级。产品定位为基于对话的学习软件：建立整体认识，沿原文细节追问，形成可回顾、可带走的结构化认知。

## 本版使用

1. 关闭旧版与开发预览窗口，再安装或运行 0.8.0，无需退出账号。原会话、原文、锚点、笔记、草稿、连接、系统凭据和 ChatGPT 注册保留。
2. 窗口的最小化、最大化/还原、关闭融入软件顶部，不再显示颜色不一致的原生标题栏；顶部空白和品牌区域可拖动窗口。
3. 输入框的回形针添加附件；文件先保存在本机，点击发送才提交给当前服务商。可以只发附件，也可配合问题发送。消息中的附件可另存原始文件。未发送附件和文字草稿会保留。
4. 麦克风打开录音卡。支持暂停/继续录音；“转写后检查”把文字放回输入框，可编辑后发送；“转写并发送”完成转写后发送文字问题。取消录音/关闭录音卡会阻止自动发送。录音不进入长期聊天备份。
5. 平时在右侧使用问题优先的路径目录；栏目右上角“展开主线概览”按主线轮次显示追问轨道。选择具体追问后保留准确原文、原回答版本、轮次和阅读位置，能返回目录、上级和来源。
6. 更多操作 → 学习笔记 → 导出离线学习笔记，生成独立 `.html` 文件。包含学习目录、章节摘要、递归追问、个人理解、可展开的完整解释/旧版本依据、来源链接；已发送附件内嵌，可离线另存。公式使用原生 MathML，无远程字体或脚本依赖。浏览器打印可保存为 PDF。
7. “请模型整理”可选，使用当前对话连接，把已保存对话文字整理成目标、核心概念、推导/例子、易错点/待解决问题和自测题。个人笔记不会进入该请求。普通本地导出不发请求；模型整理需要联网并占用所选连接用量，整理稿保留原始依据供核对，不视为已验证知识。
8. 首次安装打开和每个新版本第一次打开显示五步介绍；完成或跳过后记录当前版本。更多操作可以再次查看介绍。动画延续 Q 弹风格，并遵循系统减少动态效果。

## 附件与语音能力

| 连接 | UTF-8 文本/代码/CSV | 图片 | PDF/Office 文档 | 语音转写 |
| --- | --- | --- | --- | --- |
| OpenAI API 密钥 | 支持，按文本发送 | 需视觉模型，Responses `input_image` | Responses `input_file` 原生输入；PDF 需合适视觉模型 | `/audio/transcriptions`，默认 `gpt-transcribe`，可配置 |
| ChatGPT 套餐登录 | 支持，按文本发送 | 需支持图片的套餐模型，内联图片输入 | 本版不开放 | 官方当前登录预览不提供转写接口，需另选 API 密钥连接 |
| DeepSeek / 千问 | 支持，按文本发送 | 兼容 Chat Completions 图片；需选择支持视觉的具体模型 | 本版不开放；可自行转成 UTF-8 文本 | 只有所选地址确实支持兼容转写接口才配置转写模型；不假定普通对话连接提供 |
| 自定义兼容服务 | 支持，按文本发送 | 确认协议/模型能力后开启“图片附件” | 本版不开放 | 确认 `audio/transcriptions` 和具体模型后配置 |

- 能力随具体模型、地区、API 地址、密钥套餐变化。模型名称识别只是初始提示；连接设置可明确开启/关闭图片支持。不以模型目录读取成功代替真实附件生成成功。
- 每个附件最多 10 MiB，一次模型请求（包含保留的历史附件）最多 8 个、20 MiB。录音最多 25 MiB；文本附件纳入本地上下文预算，图片和文档的服务商 token 消耗不从字符数伪造估算。
- 图片：PNG、JPEG、WebP、GIF；文档：PDF、DOCX、PPTX、XLSX；文本/代码包括 TXT、MD、CSV、TSV、JSON、常见代码文件。当前通过文件选择器添加；拖放/剪贴板截图和独立文档阅读器继续待开发。
- 选择附件不产生上传请求；缺失附件或不兼容连接会报错并保留草稿，不静默丢文件。历史上下文缩减仍先预览确认，被省略材料不假装完整送达。
- 语音与对话服务商可分别选择。例如用 OpenAI API 转写，再把文本发送给当前 DeepSeek/千问/ChatGPT 连接。本机无需安装语音识别模型。当前为录制结束后的整段转写，不是实时流式字幕或语音通话。

官方核对（2026-10-11）：[OpenAI 文件输入](https://developers.openai.com/api/docs/guides/file-inputs)、[录音转写](https://developers.openai.com/api/docs/guides/speech-to-text)、[ChatGPT 登录预览边界](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)、[DeepSeek 视觉输入](https://api-docs.deepseek.com/guides/vision/)、[千问视觉理解](https://www.alibabacloud.com/help/en/model-studio/vision)。

## 渲染问题与数据保留

- 用户提供的截图显示数学错误区域把多段正文、列表和标题呈现为红色原始语法。截图本身没有原始 Markdown，不能认定所有细节都来自同一个具体字符。
- 已复现一行内 `$$...$$` 或段落内 `\[...\]` 未形成独立块边界时，Markdown 数学解析可能吞入后续正文。本版规范匹配的块公式边界，未匹配美元符号保留为普通可读文本；无效 TeX 在进入 KaTeX 前回退为代码文本，避免大段红色错误输出。
- 主回答、来源预览、离线笔记共用规则。所有修复仅针对显示层，保存的消息文字、revision、原文偏移和批注锚点不重写。提供模型格式提示，但不依赖模型每次都严格遵守。
- SQLite 只新增独立 `attachments` 表，不替换原工作区表，数据库版本仍为 1；工作区保存只携带附件 metadata，避免每个流式字块重新复制大文件。完整备份额外带原始附件，导入会话添加为副本；附件 ID 内容冲突拒绝覆盖本地文件。
- 备份导入上限 300 MB；原工作区正文 20 MB 保存限制保持。附件独立占用本地磁盘，删除问题后未引用的附件暂不自动清理。旧版不能完整处理新附件，回退前保留新版完整备份。

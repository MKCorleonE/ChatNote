# ChatNote 0.14.0 使用与验证

日期：2026-10-17。本版精简界面并修正空笔记行为；数据库结构、来源锚点、对话与凭据保留。

## 最终行为

- 官网只展示安装包下载，当前版本和回退入口均去掉直接启动程序；历史发行文件继续保留。
- 关于页去掉产品座右铭、介绍和源码许可说明卡，保留应用名、版本、项目仓库、更新卡和更新日志；独立许可页面及发行许可文件仍保留。
- 新对话去掉“给思考多一点空间”和两行介绍，保留品牌图标、主标题、起步建议及批注示例入口。
- 没有可用回答时，学习笔记只显示嫩芽图标与“这个对话还没有问答，探索之后再回来看看。”；不显示整理、上下文预览和导出按钮，生成请求构建也拒绝空材料。有效的已停止回答和已有追问仍可整理。
- 关闭应用内的网页默认右键菜单；键盘复制、粘贴与原有选文批注继续使用。
- 全新工作区默认简体中文；既有简中、繁中、英文选择不被覆盖。三语新增文案、版本记录与隐私政策生效版本同步，沿用弹性弹窗和按钮，尊重减少动态效果。

安装文件和本地数据位置见[Windows安装文件清单](INSTALLATION_FILES.md)。

## 验证记录

原生30项通过、5项原有显式忽略。前端、新版桌面/窄窗、安装包、签名、CI、标签及远程分发检查在完成后记录。测试失败不会记为通过；未覆盖的用户真实使用单独列出。

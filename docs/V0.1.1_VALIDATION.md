# ChatNote v0.1.1 · 连接管理升级

日期：2026-10-08。范围：Windows 连接管理；本轮未实现多语言、动画或其他平台。

## 如何使用

1. 退出旧版 ChatNote，再启动 `releases/archive/v0.1.1/ChatNote_0.1.1.exe`，或安装 v0.1.1 安装包。程序标识和数据目录保留，旧会话与 ChatGPT 连接无需重建。
2. 在 Settings 的 **Connection preset** 选择 DeepSeek、Qwen、OpenAI API 或 Custom provider，点击 **Add connection**。
3. 给连接命名，填写自己的 Key 与模型。Qwen 默认提供中国北京地域兼容地址；其他地域、业务空间和套餐使用各自控制台给出的地址。
4. **Save key** 将密钥保存到该连接独立的系统凭据条目；连接 metadata 先保存，再写入密钥，减少保存后关闭界面造成的孤立记录。
5. **Check & load models** 查询模型目录，检查当前身份。此检查不会发送对话或触发模型生成；目录存在不代表所有模型的推理权限都通过验证。
6. 点击 **Use this connection**，或在主界面右上角的下拉框直接切换。名称、地址、模型和密钥各自保留。
7. DeepSeek 的 **Refresh balance** 查询服务商实际返回的可用余额与币种，显示查询时间；不是剩余 token 估算。
8. ChatGPT/Qwen/OpenAI 余额或套餐剩余量在本版无法统一直接读取。界面明确说明并提供官方用量页面。ChatGPT 五小时/每周额度不伪造数字。

ChatGPT 当前仍为一个活动账号；新增多个 API 连接不等于同时管理多个 ChatGPT 账号。没有自动切换付费通路或自动购买额度。

## 兼容性与数据

- 旧版 OpenAI 和兼容服务商凭据条目保留，新连接使用 UUID 对应的独立条目。
- 旧 ChatGPT OAuth 注册、令牌、主机标识保持原路径。迁移只补充连接 metadata，不进行自动重新登录。
- 旧版选择的提供商和模型迁移为当前活动连接；旧兼容地址从已有公开配置 metadata 恢复。
- 聊天数据格式版本仍为 1，新增字段为兼容扩展，不重置工作区。
- 备份包含连接名称/地址/模型等 metadata，不包含 Key 或 OAuth 令牌。会话导入继续保留当前连接设置。
- 生成请求捕获所选连接 ID；新回答保存连接来源。失败时不会自动换服务商；重试优先使用仍存在的原连接。

- 实际浏览器预览：添加 DeepSeek/Qwen 连接、选择使用、主界面切换；刷新后保留四个连接和 DeepSeek 选择。

## 错误与额度边界

区别显示：未连接、地址与密钥不匹配、身份过期/错误、模型或地域无权限、目录/模型不存在、限流、额度受限、网络故障、服务商不可用。

HTTP 错误保留 status/code 和脱敏详情；兼容 `error.message`、顶层 `detail` 等形态。Responses 流内的失败同样保留服务商 code，使套餐限额与普通限流可区分。429 本身不用于推断整个套餐已耗尽或猜测重置时间。

仍需用户账号实测：DeepSeek/Qwen 的完整生成与各家特有能力，真实余额返回，ChatGPT 连接续期/撤销和服务端额度错误。当前验证包括受控 UI 模拟及原生凭据/解析测试，不把它写成每家真实账号都已通过。

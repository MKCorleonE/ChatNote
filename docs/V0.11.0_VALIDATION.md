# ChatNote 0.11.0 · 阅读修复与图片预览

日期：2026-10-13。Windows x64。沿用原数据库、凭据库与 ChatGPT 注册路径，不重置用户工作区，不改会话原文或锚点。

## 最终变化与使用方式

1. 主线与追问轮次刻度在滚动区域挂载后绑定监听；手动滚动、尺寸变化及点击定位都会更新当前轮次并加长刻度。修复首次渲染时相邻滚动容器 ref 尚未赋值导致监听缺失。
2. 主线、追问、历史消息和上下文中的图片附件显示本机缩略图；点击图片可打开大图，支持 Escape 关闭及保存原文件。文件名仍保留。图片按进入可视区域延迟读取，不为预览调用模型或上传图片。
3. 主对话上下文预览明确限制网格最小宽度与子卡片边界；长中文、网址和展开全文会换行，不再撑出小窗口。追问沿用同一布局。
4. 设置 → 模型与连接中集中放置语音服务商、转写模型和说明。语音不可用时，输入框快捷入口打开该页并定位到语音输入卡；提示同步改为正确位置。阅读与上下文保留阅读/预算设置。
5. 思维导图每次展开都重新播放弹性动画，收起时取消旧动画。系统减少动态效果时不播放。离线 HTML 保持无脚本，已有卡片拖动调宽保留。

## 验证与用户反馈

用户报告 0.10.0 刻度未随滚动变化、图片只有名称、主线上下文卡越界、语音设置位置不一致、导图第二次展开无动效。该反馈属于旧版实际使用结果；不作为 0.11.0 已验收的证据。

前端全量 131 项通过（22 个测试文件），Rust 27 项通过、5 项明确忽略，格式检查通过。新增回归覆盖相邻 ref 首次挂载后的手动滚动往返、图片缩略图/大图/保存/关闭且元数据不变、导图开关后动画再次播放，以及语音入口定位和草稿保留。三语 key/占位符与源文案覆盖通过。

隔离浏览器预览使用 1421 端口及合成对话：手动滚动四页使当前刻度由第 1 轮切到第 2 轮；主线上下文 21 张候选卡、6,600 字符中文及 6,324 字符网址的展开全文没有横向溢出（窗口 753px，卡片 699px）；390px 窄窗口预览 359px，无横向溢出。Ctrl+V 粘贴本项目图标后缩略图与大图均加载 512×512 原图。语音入口定位“模型与连接”卡片，导图反复收起/展开可操作，浏览器无警告或错误。证据存于 `.desktop-test/v0110/`，不进入用户数据库或源码。

本轮没有真实服务商推理、录音设备或覆盖安装验收。图片/文档/转写协议沿用 0.10.0 的厂商能力边界：DeepSeek PDF/Office 与转写暂不支持；真实模型权限及质量、麦克风、升级后登录保留与动画手感继续待用户验收。未新增依赖、数据库迁移、自动更新或签名。

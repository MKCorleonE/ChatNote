# ChatNote v0.3.0 · 阅读、原文批注与私人笔记

日期：2026-10-08。

## 最终行为

- 原文选区扩展到粗体、斜体、链接、相邻段落与代码文本。代码块提供整块批注与复制；公式提供整式批注，保存原始 LaTeX 与原始消息偏移。
- 数学渲染兼容 `$…$`、`$$…$$`、`\(...\)`、`\[...\]`。规范化仅用于显示，不改写已保存的回答，代码中的反斜杠保持字面内容。
- 公式按完整公式建立锚点；选取公式中的局部符号时仍使用整式来源。部分转义/实体文字会扩大到能准确定位的原文节点，避免保存错误偏移。跨消息的选区保持拒绝。
- 主线与批注可在发送前预览上下文；达到缩减条件时必须确认后发送。预览中的请求内容与实际发送一致，取消确认保留草稿和旧消息。
- 字符预算与历史摘录机制继续明确标记，尚不是精确 token 计算或语义摘要。既有来源快照、分支隔离与原文保存继续使用。
- 批注可写私人笔记；无需发送追问即可建立独立笔记。笔记只保存在本机，不进入模型请求，完整备份包含笔记，普通 Markdown 对话导出不包含笔记。
- 立即记录阅读位置，避免快速切换时丢失；取消过时的恢复任务，并在语言/字号变化后恢复。流式回答只有在跟随最新内容时继续滚动，阅读历史时可主动回到最新回答。
- 未发送的新选区保存原文来源与追问草稿，重新打开可恢复；不同选区的笔记草稿和阅读位置按原文版本分别保存。
- 新增等待模型、生成中、完成/停止/失败、耗时与字符数等小字；回答与代码分别复制。状态基于客户端实际请求/文本/完成事件，不伪造模型思考、搜索或工具运行状态。

## 登录与升级检查

- 标识、数据库、系统凭据命名保持兼容，普通升级没有自动退出账号或删除令牌的代码。
- 已保存注册但没有完整会话时显示“已保留账号注册，请登录以恢复会话”；保存的可续期会话显示自动续期可用。
- 临时刷新网络错误、429、5xx 保留会话并提示重试；实际 invalid_grant/401 提示重新授权，避免把临时故障一律当作撤销。
- 用户本轮反馈：原聊天、设置与连接都保留，但浏览器 OpenAI 授权页再次 Operation timed out。
- 本机仅检查凭据条目名称，观察到保留的账号注册，未观察到当前会话令牌。未读出/显示真实令牌，也没有清除真实注册或修改系统代理；目前不能确定令牌缺失的起因或浏览器超时根因。
- 两个独立原生进程成功写入/读取同一个随机合成测试凭据，之后清理测试条目。这证明凭据可跨进程保留，不等同于用户真实 OAuth 或真实升级安装验收。

## 已知边界

本版只交付 Windows 内测；软件尚未签名。公式使用 KaTeX 支持的 LaTeX 子集，不支持完整 TeX 宏包；复杂表格/实体选区和超大文档仍需逐例验收。法语/德语、语义摘要、精确 token 预算继续待开发。

浏览器服务端授权超时无法由本版保证修复，真实升级后自动续期、重新授权和国内厂商生成仍待用户账号验证。

先退出旧版，再运行 [安装程序](../releases/archive/v0.3.0/ChatNote_0.3.0_x64-setup.exe)或[直接启动程序](../releases/archive/v0.3.0/ChatNote_0.3.0.exe)。

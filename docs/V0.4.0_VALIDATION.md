# ChatNote v0.4.0 · 输入区与可调批注面板

日期：2026-10-08。

## 本版行为

- 右侧批注/追问树保持在右侧，支持拖动、键盘左右方向键、双击恢复默认；宽度保存在本机。窗口变窄时限制实际宽度，保留原偏好，保护主对话至少 420 像素的空间。
- 文字、工具栏与输入区随宽度重排；代码和长公式局部滚动。移动宽度继续使用覆盖面板，不显示桌面拖动入口。
- 主线与批注输入区均支持 Enter 发送、Alt+Enter 换行，也保留 Ctrl/Cmd+Enter 发送及 Shift+Enter 换行。输入法组合输入或 keyCode 229 时不触发发送；超预算时仍先审核上下文。
- 输入框内直接选择连接、模型及受支持的思考强度；连接就绪时自动读取模型目录，保存按连接/地址隔离的目录缓存。不再要求先打开设置手动检查。刷新失败保留当前选择、缓存与草稿；切换连接后丢弃旧连接迟到的结果。
- 思考强度使用账号模型目录提供的能力；目录没有该信息时，仅对已核对文档的 GPT-6.1 Sol / GPT-5.6 Sol 使用已知选项。未知模型和国内兼容通路保留服务商默认，不注入不兼容的 OpenAI 参数。
- 选定强度写入 Responses 请求的 reasoning.effort；默认强度省略该字段。答案记录保留请求强度，失败重试沿用原设置。
- 模型菜单明确标识 Work/Codex 套餐额度或厂商 API 计费，并提供用量入口，不估算剩余额度。
- 输入框聚焦/生成时显示细边框旋转渐变。设置可选两种 RGB 颜色、亮度、周期和关闭；减少动态效果时停止旋转。
- 英语、简体和繁体文案同步；原聊天、选区锚点、笔记、草稿及凭据保存方式兼容。消息附件按已讨论顺序留待下一轮。

## 官方依据

- 第三方套餐调用使用 Work/Codex 既有额度：[Sign in with ChatGPT](https://learn.chatgpt.com/docs/sign-in-with-chatgpt)。换成 GPT-5.6 Sol 不会切换到 Chat 普通聊天权益。
- [GPT-5.6 Sol 思考强度](https://developers.openai.com/api/docs/models/gpt-5.6-sol)、[GPT-6.1 Sol 思考强度](https://developers.openai.com/api/docs/models/gpt-6.1-sol)。模型可用性仍由已登录账号目录决定。
- 套餐通路使用公开 Responses 接口：[模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[通路限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。

## 使用

关闭旧程序后安装 [v0.4.0](../releases/ChatNote_0.4.0_x64-setup.exe)，或运行[直接启动程序](../releases/ChatNote_0.4.0.exe)。升级不必先断开账号。

输入框底部选择模型，旁边选择思考强度；设置中的模型 ID 和刷新入口保留为高级配置。外观设置可调整输入框光效。右侧面板边缘可拖动，双击恢复默认。

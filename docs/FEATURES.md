# ChatNote 功能清单

更新：2026-10-09。已确认沿用原型、Windows 先跑通、预留五个平台，界面简洁且有设计感，弱化历史列表并聚焦当前对话与右侧追问。P0 = 建议初版必须有；P1 = 建议下一轮；P2 = 中长期候选。具体新增范围仍可调整。

状态：已实现 / 待开发 / 待验证 / 候选 / 已验收。自动测试、助手实际检查和用户验证分别记录；Windows 的完成状态不扩展为其他平台已完成。

v0.1.0 历史状态：Windows 初版已交付，用户反馈 ChatGPT 套餐登录和对话成功。初版测试边界见 [验证记录](BUILD_AND_VALIDATION.md)。当前版本与新增 idea 见 [版本记录](CHANGELOG_AND_IDEAS.md)，最新连接升级如下。

v0.1.1 更新：DeepSeek/Qwen 预设、多连接独立保存、一键切换、身份目录检查、DeepSeek 余额查询和分类错误已实现；33 项测试通过，国内真实账号仍待实测。见 [v0.1.1 验证](V0.1.1_VALIDATION.md)。后续每次升级都同步本清单与版本记录。

v0.2.0 更新：英语/简体/繁体界面与即时语言切换已实现，38 项测试通过。原文/草稿/锚点/连接保留；法语、德语继续待开发。见 [v0.2.0 验证](V0.2.0_VALIDATION.md)。

v0.2.1 更新：登录可取消/重试、手动检查登录连接，建立私有 Git 版本管理。41 项本地测试通过；用户重试恢复登录，不归因于本版。见 [v0.2.1 验证](V0.2.1_VALIDATION.md)。

v0.3.0：扩大代码/公式/格式选区、发送前上下文确认、私人笔记、阅读位置与回答细节。51 项本地检查通过；真实升级/授权继续验证。[验证记录](V0.3.0_VALIDATION.md)。

v0.3.1：公式入口改为悬停/聚焦浮动提示；本机已观察到完整会话条目，正常关闭保留登录。用户已确认跨 v0.3.1 升级保留登录；过期续期继续验收。[验证记录](V0.3.1_VALIDATION.md)。

v0.4.0：右侧拖动调宽与响应排版、输入区模型自动目录/连接/思考强度、Enter/Alt+Enter 和 IME 保护、可定制 RGB 旋转光效。43 项前端与 16 项常规原生检查通过，浏览器交互/偏好重载通过；真实新版模型调用与升级仍待验收。[验证记录](V0.4.0_VALIDATION.md)。

v0.5.0：三按钮胶囊左栏与参考 Dendraft 的轻量过渡、分区设置及关于/更新日志/开源许可。48 项前端、16 项常规原生检查及浏览器导航/窄窗口验证通过；安装升级和手感待用户验收。[验证记录](V0.5.0_VALIDATION.md)。

开发辅助（未发布，正式版本仍为 v0.5.0）：新增双击桌面开发预览入口，小改动即时预览、积累后统一发布；默认沿用工作区和登录，启动时检查旧窗口与端口。验证与限制见 [开发预览说明](DEVELOPMENT_PREVIEW.md)，用户启动验收待完成。

对话微调（开发预览，未发布）：自适应青色提问气泡，删除角色/模型标题及回答完成统计；提问操作悬停显示，回答复制/上下文为小图标，回答时间悬停显示。今天/星期/月日分层日期、图标随阅读字号缩放；已有手动气泡尺寸保留。主线与批注版本和来源仍保留，63 项前端检查、悬停/字号/窄窗口检查通过，真实账号与日常手感待用户验收。[使用与验证](PREVIEW_CHAT_REFINEMENTS.md)。

连接恢复（开发预览，未发布）：启用 Windows 系统代理支持，连接建立前最多三次尝试，服务器已收到的请求不自动重发；增加 TLS 等固定诊断码和三语提示。64 项前端、21 项常规原生检查通过，公共认证/API 地址可响应；真实账号发送仍待用户验收。[验证与边界](PREVIEW_CONNECTION_RECOVERY.md)。

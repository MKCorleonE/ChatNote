# 对话界面微调 · 开发预览

日期：2026-10-09。正式版本仍为 v0.5.0，本轮仅更新开发源码，没有新安装包或版本标签。

## 使用

关闭正式版后双击根目录的 [启动开发预览.cmd](../启动开发预览.cmd)。已打开的开发窗口通常会自动刷新；若没有变化，关闭开发窗口和启动终端后重新打开入口。

- 提问使用内容自适应的青色气泡，短句收窄，长句自动换行增高；取消“你”标题。主线与批注采用相同交互，深浅主题分别调整底色和文字对比。
- 气泡下方依次提供复制、编辑图标，以及本次提问的本地 24 小时时间 `HH:mm`。旧问题继续使用原发送时间，新问题版本使用重发时间。
- 点击编辑，在原位置调整文字，选择“保存并重新生成”才发送；取消不修改原消息。普通 Enter 在编辑框内换行，Ctrl/Cmd+Enter 可保存并重发，输入法组合键不会误发。
- 编辑较早的问题时，新请求仅使用该问题之前的当前版本历史与修改后的问题；原回答和原后续对话保留，可通过问题下方的版本箭头找回。切换版本不发送模型请求。
- 主线与批注各自管理版本；编辑批注不会把旁支消息写入主线。旧批注继续锚定原回答，跳回来源时自动显示包含旧来源的版本。生成期间禁用编辑与版本切换。
- 回答复制采用图标按钮，保留可读的悬停提示和无障碍名称；回答开头不再显示 ChatNote 或模型名。上下文查看移至回答下方，示例提示和生成状态继续保留。
- 青色仅用于提问气泡，不作为最终品牌色，其他界面配色仍待后续统一。

## 数据与限制

- 保留原消息的 ID、revision、正文、发送时间以及批注锚点；新增独立消息与当前显示路径、历史路径。工作区版本和 SQLite 格式未改变，连接 metadata、系统凭据与 ChatGPT 注册沿用原方式。
- 完整工作区备份包含历史版本；Markdown 导出包含“已保留的问题版本”章节和关联批注。反复编辑会增加本地记录体积；每个主线/批注最多保留 1000 条历史路径，达到上限时明确提示，不删除旧记录。
- 原 v0.5.0 可以读取保留的消息，但不具备新版本选择界面，会顺序显示保留的多个版本；编辑后建议继续在开发预览中使用，待统一交付后再更新正式版。
- 实际厂商的编辑重发、系统剪贴板、原生窗口手感与日常使用仍待用户验收。自动生成流程使用受控模拟通信验证，没有消耗用户模型额度。
- I32 对话界面精简已在开发预览实现；I15 的问题编辑重发与版本保留已实现，直接对回答重新生成及回答编辑仍待开发。正式发布归属待统一交付时补充。

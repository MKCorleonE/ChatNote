# ChatNote 0.9.0 · 学科整理与离线导图

日期：2026-10-12。Windows x64 升级；新增可选偏好，不改数据库版本、应用标识和凭据路径。

## 使用

1. 先关闭旧版与开发预览窗口，再运行或安装 0.9.0，无需退出账号。保留已有会话、精确锚点、草稿、附件、笔记、连接和 ChatGPT 注册。
2. 启动画面图标放大至 112px、品牌至 38px，最少展示约 1.5 秒，再平滑收回。工作区加载更慢时继续展示加载状态。新座右铭同步启动、空会话、学习笔记和导图：简体“探索每一个问题，同时不偏离主线。”；繁体“探索每一個問題，同時不偏離主線。”；英文“Explore every question without losing the thread.”。
3. 顶部追问树旁新增学习笔记（书本图标）和思维导图（节点图标），入口不再藏在更多操作中。
4. 学习笔记的“学科预设”提供通用学习、数学、计算机科学、自然科学、人文与社会科学。预设全文直接可见；“自定义此提示词”可编辑。自定义区输入名称后点击“保存这个预设”，保存至本机工作区。可重新选择内置学科恢复原预设，也可返回自定义内容；自建预设可删除，最多 40 个。完整工作区备份携带这些偏好，单会话导入不覆盖全局偏好。
5. 默认模型输出采用六节：学习目标、核心概念与联系、推理过程与例子、易错点/不确定性/待解问题、主线与追问联系、自测与下一步。学科提示强调各自的证明、复杂度、实验证据或多元解释。关键结论要求引用原消息 ID，并区分原始依据、补充例子与未验证结论。用户可以自定义格式；模型是否严格遵守仍需核对。
6. “预览整理上下文”不发模型请求，展示连接地址、模型、完整提示词、真实发送的对话文字及字符数。发出整理后显示该次请求快照，生成中也可检查。改变提示词后重新预览下一次请求。发送当前已保存的主线与追问路径、原文引用和附件省略说明；私人笔记、未发送草稿、旧路径正文、附件字节和凭据不进入整理请求。完整的依据与语言规则也可单独展开查看。
7. 整理按钮旁显示转圈、等待/生成状态、秒数和已接收字符；正文流式显示。服务商没有总长度，所以不伪造百分比。可停止；中断稿标为未完成，导出也标识部分内容。整理稿当前保留在该窗口，关闭前导出以留存；提示词预设则长期保存在本机。
8. 思维导图根据实际已保存的会话在本机生成，不额外调用模型。主线轮次纵向排列，追问层级从左向右展开；卡片显示问题标题和正文摘要，点击展开完整问答、精确引用、个人理解和已保存的问题版本。旧回答上的追问归入明确的旧版本区域。应用内导图可打开原追问；导出包含完整来源回答供离线核对。
9. “导出思维导图 HTML”得到单文件，无远程脚本、图片或字体。现代电脑/手机浏览器可打开、触摸横向滚动、展开细节；公式使用原生 MathML。导图只列附件名称，原始附件仍可从学习笔记导出；文件包含本地个人笔记，分享前自行查看内容。
10. 追问树右上角展开概览后，可用“主线目录／横向导图”按钮切换；布局偏好跨重启保存，不改已有目录折叠与阅读位置。
11. 新人介绍变为贴着实际设置、追问树、附件、学习笔记按钮的五步气泡，带目标高亮、前进/后退、跳过和重看。首次或新版本首次展示，完成/跳过保存版本。气泡、菜单、卡片、展开与收回采用统一弹性曲线，遵循系统减少动态效果。

## DeepSeek 官方接口核对

截至 2026-10-12：[图像理解](https://api-docs.deepseek.com/zh-cn/guides/vision/)明确列出 `deepseek-flash` 的图片输入，支持 JPEG/PNG/GIF/WebP，可内联 Base64、外部图片 URL 或 file_id。[Files API](https://api-docs.deepseek.com/zh-cn/guides/files_api/)提供图片上传 `POST /files`，单图最多 64 MiB；这不是 PDF/Word/任意文件解析接口。官方公开文档未列出语音转文本端点，不把 OpenAI 格式兼容当作支持 `audio/transcriptions`。

ChatNote 已有 DeepSeek 图片内联通路；模型选择 `deepseek-flash` 或明确开启视觉能力。TXT/MD/代码/CSV 等文件可读取成 UTF-8 文字后送入对话，区别于厂商直接接收原始文档。本版未额外实现 DeepSeek file_id 管理。语音可用独立 OpenAI/实际提供兼容转写接口的 API 连接，转写文字再交给 DeepSeek。查询配额/连接目录不自动生成答案。

## 验收边界

用户尚未验收本版真实安装升级、启动动画手感、真实模型整理质量与语音转写，以及真实 iOS/Android 文件打开体验。窄屏浏览器检查不等于移动端真机验收。模型整理预设规范输出，但不能保证每个模型都完全遵守格式。导图是原会话结构的可展开阅读与导出，不是拖拽编辑器，也不自动创造关系或知识结论。未加入签名、自动更新、云同步、直接 PDF 生成或模型自动计费探测。

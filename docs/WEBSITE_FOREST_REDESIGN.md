# 官网1.1.0 · 沿主线进入森林

日期：2026-10-13。用户确认视觉方向后实施；客户端仍为0.12.0，本轮只重构独立官网。

## 最终设计

首页恢复“探索每一个问题，同时不偏离主线。”及繁体/英文原文。底层大号ChatNote字样与五棵错落树、弯曲主线构成中性矢量场景。下滑时镜头沿主线推进，树木轻微位移，字样和图标逐渐退场；功能内容在退场时进入，避免空白停留。向上滚动可恢复初始画面，不接管滚轮、不强制翻页。

首页收敛为森林开场、三个功能和下载：原文追问、上下文选择、学习导出。功能画面随阅读位置切换，也可点击标签跳转；手机采用逐项展示。移除视频、章节播放器及MP4入口；原素材在旧Git提交与本机忽略测试目录保留，不处理任何历史安装包。

详细下载/校验、FAQ和联系改为三语独立页面。加上既有指南、隐私、使用说明、更新日志和试用清单，共27个三语页面；另保留404和合成导图，合计29个HTML文件。旧页面地址、features/download锚点、隐私和公开Release入口兼容。

色彩/字体/间距集中在`assets/tokens.css`。大面积炭灰中性色、1px边界、6/8px圆角、无渐变与大阴影；薄荷色用于CTA、选中状态和正在探索的主线。按钮、展开、2.4秒复制提示保留克制弹性。系统减少动态效果时，森林静态呈现、开场缩短为一屏，功能和下载仍可使用。

功能示意为合成内容，未发送模型请求。上下文示意可勾选来源回答和追问历史；引用/当前问题固定保留，其他追问禁选，私人笔记排除。关闭再切换功能标签，示意选择在本页保留；不建立账号或上传这些示意选择。官网隐私说明同步三语。

## 验证与证据

- `npm run build`构建27页成功；`npm run check`验证三语键及数组结构、29个HTML、561条本地资源链接、两个版本元数据。
- JavaScript语法检查通过；首页不包含视频播放器或MP4链接。下载版本数据SHA-256与重构前一致。
- 隔离浏览器4174：桌面1280px与手机390/320px排版无横向溢出。三语首页以及下载、FAQ、联系、隐私共12个详情页面均检查；英文窄屏导图示意没有内部横向溢出。
- 森林随滚动缩放、主线从下方向森林推进、字样和图标退场；功能标签切换、上下文1/2选择及切换保留、旁支禁选、公开下载入口均正常。浏览器无警告/错误，面板实测无阴影。
- 桌面主页可见字符约372，手机展示三个界面示意后约482；首版检查约1732。用于说明精简效果，统计包含界面标签。截图在`.desktop-test/site-redesign/`，不包含私人聊天。
- 减少动态效果的CSS和事件分支静态检查，没有替用户切换系统设置；真实手机触摸、不同硬件的滚动手感仍待用户体验。
- 向上返回首屏实测恢复到scrollY=0、森林/字样不透明度1、镜头scale=1。正式网址已实际打开：原座右铭、森林场景和新布局生效，无视频控件及横向溢出；线上截图为`live-forest.jpg`。

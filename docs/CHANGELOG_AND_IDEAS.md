# ChatNote 版本记录与待实现想法

更新：2026-10-17。

本文件记录正式版本、用户实际验证、未来版本建议和待实现想法。每次应用升级后必须同步本文件，并更新功能状态与交付说明；该约定已加入项目 AGENTS.md。

## 记录规则

- 已发布/已交付版本记录最终行为、验证证据和已知限制。
- 原型阶段不算正式应用版本，不把演示包版本与客户端版本混用。
- “已实现”“自动测试通过”“实际使用验证”分别记录；用户反馈注明来自用户，不扩展为未进行的测试。
- 未来版本号和范围是建议，讨论确定后再开始开发；未交付的内容不会写进已发布版本。
- 新想法使用稳定编号；完成后记录所属版本，继续保留历史。
- 每次版本发布补充变更、修复、数据迁移、测试和未完成项。

## 服务商接入讨论 · 核对于 2026-10-08

API 是接入形式；Plan 是额度/计费安排。有些套餐仍使用专属 API Key，不能把“用 Key”与“用套餐”看成相反概念。

| 通路 | 当前判断 | ChatNote 建议 |
| --- | --- | --- |
| DeepSeek 官方 API | 官方提供 Key 与兼容协议 | 现有兼容入口可尝试；优先补配置预设与实测 |
| Qwen / 阿里云百炼普通 API | 支持 OpenAI Chat 接口；地域和业务空间决定地址 | 从控制台取得匹配的 Key、Base URL 和模型 ID |
| 阿里云 Token Plan | 使用专属 Key/地址；有产品版本及使用范围区别 | 评估具体订阅是否适用，再开发/标识套餐支持 |
| ChatGPT Plan | 用户已验证登录与对话 | 继续补生命周期与清晰的额度/连接状态 |

DeepSeek 当前首次调用文档使用 `https://api.deepseek.com`，列出 `deepseek-flash` 和 `deepseek-v4-pro`；模型 ID 后续仍应依据控制台/官方目录核对，不固定沿用旧别名。[DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)

Qwen 普通 API 支持兼容接口。百炼目前有业务空间专属域名，各地域 Key 不通用；预设应支持控制台提供的地址，避免把一个旧地址固定用于所有用户。[百炼兼容说明](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)

Token Plan 团队版 FAQ 列出 Cherry Studio、Chatbox 等兼容工具；概述仍要求交互式工具使用，排除应用后端/自动化脚本。个人版也有使用范围限制。判断 ChatNote 是否适用时，需要核对具体套餐和交互方式；协议兼容不等同于已获得厂商认可。这里尚未得到厂商对 ChatNote 的明确确认。[团队版 FAQ](https://help.aliyun.com/zh/model-studio/token-plan-team-faq)、[团队版范围](https://help.aliyun.com/zh/model-studio/token-plan-team-overview)、[个人版范围](https://help.aliyun.com/zh/model-studio/token-plan-personal-overview)

当前可以在 Settings 选择 OpenAI-compatible provider，填写服务商自己的 Base URL、Key 与模型 ID。它具备尝试通路，但本轮没有替用户连接国内账号或调用模型，也没有验证思考内容、多模态和每家特殊参数。

目前确认到的官方联系渠道：[Request a client ID](https://developers.openai.com/siwc/request-client-id) 中的 Sign in with ChatGPT interest form。该渠道针对商用合作意向；付费/远程托管产品也应按官方指南确认接入形式。公开文档尚未说明一个自助“名称认证”按钮，或保证商用申请能消除此提示。[适用范围](https://developers.openai.com/siwc/token-sharing-open-source)

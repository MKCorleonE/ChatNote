# ChatNote 0.6.0 · Windows x64

- `ChatNote_0.6.0_x64-setup.exe`：新安装程序。
- `ChatNote_0.6.0.exe`：直接启动程序，需系统具备 WebView2。
- `SHA256SUMS.txt`：当前与全部保留交付文件校验值。

关闭旧版和开发预览窗口及其启动服务，再启动新程序或安装；无需先断开账号。原对话、批注、草稿、连接、凭据与 ChatGPT 注册路径保留，升级前可在更多操作导出工作区备份。

本版汇总气泡/问题编辑与保留版本、悬停图标/时间、删除与历史固定、逐轮追问树、圆角弹性动效和连接恢复。新增空会话不进入历史（发送第一条消息后显示，失败会话保留；草稿保留），批注原文和树来源渲染公式。设置 → 更新日志包含三语完整记录。

本地常用目录保留 0.6.0 与 0.5.0；0.4.0 在 `archive/v0.4.0`，更早版本继续保留。旧文件不替换。回退前备份，新版问题版本功能在旧版没有相同选择界面。

[本版验证与限制](../docs/V0.6.0_VALIDATION.md) · [项目版本记录](../docs/CHANGELOG_AND_IDEAS.md) · [私有 v0.6.0 Release](https://github.com/MKCorleonE/ChatNote/releases/tag/v0.6.0)。私有下载需仓库访问权限。实际安装升级、真实账号调用和日常手感仍待用户验收；当前仍未签名、手动更新，其他平台未交付。

继续开发可双击根目录 [启动开发预览.cmd](../启动开发预览.cmd)，默认共享正式版工作区与登录。[开发预览说明](../docs/DEVELOPMENT_PREVIEW.md)。

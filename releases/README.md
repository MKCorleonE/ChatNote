# ChatNote 0.7.1 · Windows x64

- `ChatNote_0.7.1_x64-setup.exe`：安装程序。
- `ChatNote_0.7.1.exe`：直接启动程序，需系统具备 WebView2。
- `SHA256SUMS.txt`：全部当前和历史交付文件校验值。

先关闭旧版及开发预览窗口/启动服务，再启动新版或安装，无需退出账号。保留原会话、锚点、笔记、草稿、连接、系统凭据与 ChatGPT 注册路径。升级前可在更多操作导出工作区备份。

本版将作者选定的五棵错落轮廓树与蜿蜒探索主线应用到软件/安装包及启动/欢迎/关于/浏览器标签图标。原有 0.7.0 功能保留，三语更新日志同步。

常用目录保留 0.7.1 与 0.7.0；0.6.0 及更早已交付版本归档保留，移动前后检查 SHA-256。回退前备份工作区。

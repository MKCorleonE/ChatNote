# ChatNote 0.3.0 · Windows x64 内测版

- `ChatNote_0.3.0_x64-setup.exe`：最新安装程序。
- `ChatNote_0.3.0.exe`：最新可直接启动程序，需要系统具备 WebView2。安装包会按 Tauri 方式处理该运行时。
- v0.2.1 保留为上一版；v0.2.0 及更早版本位于 `archive` 的对应目录。
- `SHA256SUMS.txt`：全部已交付文件的校验值。

先关闭旧程序，再启动 v0.3.0 或运行新安装包。升级保留原会话和注册信息；关闭程序即可，不需要先在连接设置中断开账号。打开左下角 **Settings → Interface language**，选择 English / 简体中文 / 繁體中文，立即生效并自动保存。

新版本支持格式/段落/代码/完整公式批注，补齐常见数学分隔符；批注区可保存私人笔记，发送前可预览上下文，缩减时必须确认。新增回答状态小字、耗时、字符数与复制入口，并恢复阅读位置和未发送的原文选区。

ChatGPT 登录等待中可以取消并重试；手动“检查登录连接”不调用模型。浏览器授权页超时时，取消本次尝试，关闭旧授权页再重新登录。本轮用户重试已恢复，这不代表新版修复了服务端故障。

[私有 v0.3.0 下载](https://github.com/MKCorleonE/ChatNote/releases/tag/v0.3.0) / [v0.2.0 与历史安装包归档](https://github.com/MKCorleonE/ChatNote/releases/tag/v0.2.0)。需要登录有仓库权限的 GitHub 账号。

界面语言不翻译原来的聊天、引用或连接名称；模型回复继续跟随提问。法语、德语尚未提供。

**添加连接**支持 DeepSeek/Qwen 等预设，各自保存 Key/地址/模型；主界面右上角切换连接。**检查并加载模型**只检查目录，不触发生成；DeepSeek 支持主动查询余额，其他套餐/额度使用官方用量入口。

记录在本机保存，右上角菜单可导出 Markdown 或完整备份；备份不包含密钥与登录令牌。真实厂商请求、登录生命周期和本版升级安装仍需分别验收。

51 项本地检查通过，包括跨进程凭据持久化。用户浏览器授权页仍曾超时，无法保证本版修复外部授权故障。详细范围见 [v0.3.0 验证](../docs/V0.3.0_VALIDATION.md)、[版本记录](../docs/CHANGELOG_AND_IDEAS.md)和[版本保留规则](../docs/RELEASE_POLICY.md)。当前仍是未签名内测版，无云同步/自动更新，其他平台尚未交付。

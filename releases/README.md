# ChatNote 0.5.0 · Windows x64 内测版

小改动开发预览不需要重新安装：先关闭正式版，再双击项目根目录的 [启动开发预览.cmd](../启动开发预览.cmd)。首次编译可能需要数分钟，使用时保留命令窗口；默认沿用原工作区和登录，预览操作也会保存。详见 [开发预览说明](../docs/DEVELOPMENT_PREVIEW.md)。本目录交付文件仍为正式 v0.5.0，不会随开发源码变化。

- ChatNote_0.5.0_x64-setup.exe：最新安装程序。
- ChatNote_0.5.0.exe：最新直接启动程序，需要系统具备 WebView2。
- v0.4.0 保留为上一稳定版；v0.3.1 及更早版本在 archive，原始文件和校验值保留。

关闭旧版后安装或启动新版，无需先断开账号。既有对话、批注、原文锚点、草稿、连接 metadata 和系统凭据路径保留。此前用户确认 v0.3.1 升级保留登录；本版真实安装升级与续期仍待用户验证。

胶囊从上到下：加号新建、三横线历史、齿轮设置，共三个按钮，无协作入口。历史和设置提供轻柔展开/收回动效；系统减少动态效果时禁用动画。

设置导航：模型与连接、阅读与上下文、外观、数据与隐私；关于组包含关于、更新日志、开源许可。切换分区保留未保存表单；完成保存，关闭放弃未保存编辑，界面语言即时应用。

数据与隐私可备份/导入，导入作为副本添加，不覆盖原有对话与连接。开源许可可搜索并展开原始条款；ChatNote 仓库仍为私有。更新日志提供本地记录和私有 Release 入口，目前仍需手动更新。

保留 v0.4.0 输入框的模型/连接/思考强度、Enter/Alt+Enter、IME 保护、可调 RGB 光效和右侧面板调宽。消息附件继续待开发。

48 项前端与 16 项常规原生检查通过，编译/格式检查通过；助手浏览器实际检查导航、许可搜索、焦点与 390 像素窄窗口无溢出。未发送真实推理请求；用户尚未验收本版手感与安装升级。

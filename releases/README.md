# ChatNote 0.10.0 · Windows x64

- `ChatNote_0.10.0_x64-setup.exe`：安装程序。
- `ChatNote_0.10.0.exe`：直接启动程序，需要系统具备 WebView2。
- `ChatNote_0.10.0_mind-map-example.html`：合成会话的多级离线导图，可拖动卡片调宽。
- `SHA256SUMS.txt`：32 个当前与历史交付文件的校验值。

先关闭旧版和开发预览，再安装或启动，无需退出账号。原会话、锚点、笔记、草稿、附件、连接、凭据及 ChatGPT 注册路径保留。回退前导出完整工作区备份。

主对话／追问框 Ctrl+V 粘贴图片；DeepSeek 选 deepseek-flash，PDF／Office 暂不开放，UTF-8 文本可用。OpenAI API 和千问 Qwen-Long／Qwen-Doc 可处理支持的文档。语音默认模型已修正，千问 ASR 和兼容转写连接可作为独立语音服务，自动选择会跳过空密钥连接。

追问发送前逐项选择本次来源历史和当前追问历史；主线预览也可按选择发送。精确引用与当前问题保持携带，显示预算后的实际请求。上下文预算限制聊天携带文字，不是模型 Token 配额或回答长度；短对话未达到阈值时不会缩略。

导图有父子连线、360px 默认宽度、统一滑杆和单卡拖动调宽；独立 HTML 也能调宽。主线／追问多轮刻度跟随阅读位置。底部提示 2.5 秒弹性进出，成功导出笔记／导图发射彩带；减少动态效果时关闭动画。

127 项前端、27 项常规原生、格式及最终构建通过。合成上下文／刻度／导图、81 轮末轮可见性、390px 布局和独立 HTML 实际拖动已检查。真实密钥请求、麦克风设备、安装升级与动画手感待用户验收。[使用、验证与限制](../docs/V0.10.0_VALIDATION.md)。

常用目录保留 0.10.0 与上一稳定版 0.9.0；0.8.0 及更早已校验归档，历史交付文件不删除或替换。未签名、手动更新；其他平台暂未交付。源码通过私有 PR 复核，正式 GitHub Release 由维护者决定。

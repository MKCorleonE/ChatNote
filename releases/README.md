# ChatNote 0.4.0 · Windows x64 内测版

- ChatNote_0.4.0_x64-setup.exe：最新安装程序。
- ChatNote_0.4.0.exe：最新直接启动程序，需要系统具备 WebView2。
- v0.3.1 保留为上一版；v0.3.0 及更早版本位于 archive 对应目录，原始文件与校验值保留。

关闭旧程序，再安装或启动新版，不用先断开账号。用户已确认 v0.3.1 升级保留登录；本版真实升级与过期续期仍分别验收。

右侧批注/追问树边缘可以拖动调宽，双击恢复默认，也可聚焦分隔线用方向键调节。窗口变窄时限制实际宽度，重开保留偏好。

模型、连接和思考强度在输入框底部选择。连接就绪后自动读取模型目录并缓存，不必先打开设置检查；读取失败保留当前模型和草稿。设置仍提供高级模型 ID/刷新入口。ChatGPT 套餐调用使用 Work/Codex 额度，换成 5.6 Sol 仍使用同一套餐通路；API 连接按服务商计费。

Enter 发送、Alt+Enter 换行；Ctrl/Cmd+Enter 与 Shift+Enter 保留。中文输入法确认不会误发送；发送前上下文预览和缩减审核仍保留。

设置 → 阅读与外观 → 输入框光效：可选两种 RGB 颜色、亮度、周期和关闭。光效在聚焦或生成时显示，减少动态效果时停止旋转。

英语/简体/繁体界面保留；语言不翻译原文和模型回复。附件按讨论顺序留待下一轮。

本版 43 项前端检查、16 项常规原生检查通过；浏览器实际拖动、响应排版、颜色/强度/草稿重载通过。没有为测试消耗真实模型生成额度。尚未验证本版真实账号思考参数请求、安装升级或移动真机。

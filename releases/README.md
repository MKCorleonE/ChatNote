# ChatNote 0.9.0 · Windows x64

- `ChatNote_0.9.0_x64-setup.exe`：安装程序。
- `ChatNote_0.9.0.exe`：直接启动程序，需系统具备 WebView2。
- `ChatNote_0.9.0_learning-note-example.html`：合成会话的离线笔记样例。
- `ChatNote_0.9.0_mind-map-example.html`：合成会话的多级可展开思维导图样例。
- `SHA256SUMS.txt`：29 个当前与历史交付文件校验值。

先关闭旧版和开发预览窗口/服务，再安装或启动，无需退出账号。原会话、锚点、笔记、草稿、附件、连接、凭据和 ChatGPT 注册路径保留。

顶部追问树旁新增无文字的学习笔记和思维导图入口。整理提示词全文可见，提供五类学科预设，可自定义/保存/恢复；预览完整请求上下文，生成时显示等待秒数、流式字数与转圈，可停止。模型整理稿关闭窗口前需导出留存，预设则长期保存在工作区。

思维导图按实际主线和递归追问在本机生成，卡片可展开问答、原文依据、私人笔记和已保存版本；导出独立 HTML，可在现代电脑或手机浏览器打开/横向滚动，无网络、脚本或字体依赖。附件原文件从学习笔记导出。追问概览可切换横向导图，新人引导变为按钮旁的分步气泡，启动图标与文字放大、延长展示，并同步新座右铭。

DeepSeek `deepseek-flash` 支持视觉图片，官方 Files API 上传的是图片；PDF/Office/任意文档和语音转写不是据此默认支持的接口。ChatNote 可读文本附件后发送文字，也可用独立 API 服务商转写，再让 DeepSeek 回答。详见 [使用、验证与限制](../docs/V0.9.0_VALIDATION.md)。

117 项前端、24 项常规原生、Windows CI 和最终 NSIS 构建通过；最后快照/焦点/文案微调的定向检查通过。合成界面、独立原生测试身份和 390px HTML 布局已检查。真实整理质量、安装升级、手机真机与动效手感待用户验收。

常用目录保留 0.9.0 与 0.8.0，0.7.1 及更早已交付文件校验后归档；历史文件不删除或覆盖。回退前保存新版完整备份。未签名、手动更新，其他平台客户端未交付。

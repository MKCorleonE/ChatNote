# ChatNote 0.7.0 · Windows x64

- `ChatNote_0.7.0_x64-setup.exe`：安装程序。
- `ChatNote_0.7.0.exe`：直接启动程序，需系统具备 WebView2。
- `SHA256SUMS.txt`：全部当前和历史交付文件校验值。

先关闭旧版及开发预览窗口/启动服务，再启动新版或安装，无需退出账号。保留原会话、锚点、笔记、草稿、连接、系统凭据与 ChatGPT 注册路径。升级前可在更多操作导出工作区备份。

本版修复问答成对删除和上下文预览；精简追问树，提供返回概览与精确原文定位；菜单统一弹性和外部关闭；笔记圆角、胶囊氛围灯开关/RGB 调色/颜色复位；六种荧光笔色和不透明度统一文字与公式高光。设置 → 更新日志提供完整三语记录。

常用目录保留 0.7.0 与 0.6.0；0.5.0 及更早已交付版本归档保留，移动前后检查 SHA-256。回退前备份工作区。
